# 📊 Automação de Relatório de Vendas com Python

## 🚀 Sobre o projeto
Este projeto automatiza a geração de relatórios de vendas a partir de uma planilha Excel, eliminando tarefas manuais e aumentando a eficiência na análise de dados.

A solução foi desenvolvida para empresas que precisam processar grandes volumes de informações de forma rápida, confiável e organizada.

---

## ⚙️ Funcionalidades
- Leitura automática de dados de uma planilha Excel
- Tratamento e organização das informações
- Geração de relatório estruturado
- Redução de erros manuais
- Otimização do tempo de execução

---

## 💡 Benefícios
- Economia de tempo em tarefas repetitivas
- Maior precisão nos dados
- Facilidade na tomada de decisão
- Processo automatizado e escalável

---

## 🛠️ Tecnologias utilizadas
- Python
- Pandas
- OpenPyXL

---

## ▶️ Como executar Aplicações reais

1. Instale as dependências:
```bash
pip install pandas openpyxl
```
2. Abra o arquivo excel_automation.ipynb no VS Code

3. Execute as células em sequência para rodar a automação
